Установка BlitzForge

Один установщик ставит в игру всё, что нужно, чтобы моды с этого сайта работали: загрузчик модов, Lua-хост, команду wotbmod, кнопку «Установить в игру» для браузера и недостающие системные зависимости. Только Windows и только клиент World of Tanks Blitz {{client_build}}; установщик проверяет сборку и ничего не меняет в другой.

Как установить

  1. Закройте игру. Запустите BlitzForge-Setup-…exe: обычный мастер установки Windows.
  2. Мастер сам найдёт папку игры через Steam и проверит сборку клиента. Если игра в другом месте, укажите папку на шаге «Папка игры».
  3. Компоненты: загрузчик и Lua-хост ставятся всегда; «Команда wotbmod» и «Кнопка «Установить в игру»» включены по умолчанию; «Python для разработчиков» нужен только тем, кто пишет моды. Недостающие зависимости (Visual C++ Runtime x86, Python) установщик докачает сам.
  4. Нажмите «Установить». Каждый файл проверяется по хешу, исходные хранятся под mods\cache\install_backups; удаление доступно через «Приложения» Windows.

Архив .zip рядом — тот же набор для ручной установки: powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -RegisterLauncher -AddToPath из папки архива; verify.ps1 сверяет установку.

Как ставить моды

  1. Откройте мод в каталоге и нажмите «Установить в игру». Браузер передаст ссылку установщику, он покажет права, зависимости и хеш и спросит подтверждение.
  2. Из терминала (после установки откройте новое окно): wotbmod install <id> --catalog {{base_url}}/api/v1.
  3. Посмотреть, что стоит: wotbmod list. Убрать мод: wotbmod uninstall <id>. Вернуть прошлую версию: wotbmod rollback <id>. Моды, которые меняют файлы игры, при удалении возвращают оригиналы.

Как удалить

«Приложения» Windows → BlitzForge → Удалить (или uninstall.ps1 из архива): возвращает исходные файлы игры, убирает команду из PATH и регистрацию кнопки. Если что-то менялось после установки, удаление остановится и ничего не тронет.

Что важно знать

  • Это preview: после обновления игры набор перестаёт подходить, пока не выйдет версия под новую сборку.
  • Файлы подписаны ключами blitzforge-preview-2026 и портала blitzforge-portal-2026; установщик отказывается менять чужой version.dll или чужой загрузчик.
  • Хеш архива указан рядом со ссылкой. Скачивайте набор только с этого сайта.
