# LIVE failures

Этот файл является пустым шаблоном. Runtime-файл создаётся в
`mods/data/wotbmod.native_validation/LIVE_FAILURES.md` и дополняется только
после ручного FAIL или восстановления crash marker.

Crash marker указывает последнюю активную экспериментальную операцию, но сам
по себе не доказывает причинность сбоя.
