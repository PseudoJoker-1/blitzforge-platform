# Ночной режим

Пакет ресурсов (`"type": "resource"`): заменяет два шейдера цветокоррекции в
`Data/Materials/Shaders/`, чтобы боевая сцена стала ночной. Интерфейс и
gameplay-оверлеи (пробитие, outline) не затрагиваются: их ветка в шейдере
защищена `#if !HIGHLIGHT_COLOR && !HIGHLIGHT_WAVE_ANIM`.

`wotbmod install` сверяет, что на диске лежит именно стоковый файл
(`stock_sha256`), сохраняет его в `mods/cache/game_files/` и записывает
новый DVPL; `wotbmod uninstall` возвращает оригинал. Патч привязан к сборке
клиента `11.20.0.887`: после обновления игры стоковые хеши меняются и пакет
нужно переиздать.

Проверка: `python ../../test_night_mode.py` из `_mod_tools` сверяет, что
патч не трогает gameplay-оверлеи.
