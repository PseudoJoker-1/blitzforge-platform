# Lua Battle Telemetry

Практический боевой event feed на Lua. Он показывает последние типизированные
события клиента:

- полученный урон и оставшийся HP;
- состояние и остаток перезарядки;
- выбранный снаряд и боекомплект;
- смену режима камеры;
- выстрелы, попадания и local-shell события;
- начало и завершение боя.

Кнопка `ПАУЗА` замораживает журнал, `ОЧИСТИТЬ` удаляет накопленные строки.
Callback-и только записывают данные в Lua-очередь; изменение DAVA controls
выполняется на следующем `on_frame`, поэтому UI не перестраивается внутри
native event dispatch.

Интерфейс существует только в `BATTLE`, `TRAINING` и `REPLAY`, а при
`MOD_SCREEN`/`TEXT_INPUT` полностью размонтируется вместе с callbacks. Поэтому
он не перекрывает каталог модов и не перехватывает ввод поверх него.
