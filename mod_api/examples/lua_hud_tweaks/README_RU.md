# Lua HUD Tweaks

Цвет и размер прицела, размер миникарты, цвет индикатора попадания, позиция
журнала урона и поля счётчиков — через `wotb.hud`; режим камеры и FOV боя —
через `wotb.view`. Правки применяются через 20 с после `battle.started`
(на экране загрузки контролов HUD ещё нет) и откатываются `wotb.hud.reset()`
в конце боя и при отключении.

Каждый отказ клиента печатается его словами (например, слот, который
11.20.0.887 не поддерживает). Шаблон: `wotbmod new ... --type lua --template hud`.
