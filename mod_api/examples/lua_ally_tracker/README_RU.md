# Lua Ally Tracker

Боевой Lua-мод, который показывает только публичные данные союзной команды:

- имя и public ID;
- команда и public type;
- HP, максимальный HP, процент и состояние машины;
- сколько времени прошло с последнего публичного обновления;
- последнюю подтверждённую позицию, но только если API выставил
  `position_available = true`.

На текущем native fingerprint координаты машин ещё не имеют проверенного
источника. Поэтому мод показывает `позиция API недоступна`, а не выдаёт нулевой
вектор за реальные координаты. Когда bridge начнёт публиковать подтверждённую
позицию, этот же Lua-код автоматически начнёт сохранять и показывать её.

Мод не создаёт записей для противников и не сохраняет скрытые enemy state.
Интерфейс монтируется только в `BATTLE`, `TRAINING` или `REPLAY`, полностью
удаляется вне этих контекстов и всегда блокируется в `MOD_SCREEN` и
`TEXT_INPUT`, поэтому кнопку каталога модов он не перекрывает.

Нажмите строку союзника, чтобы открыть подробности. Кнопка `–` сворачивает
список, не отключая сбор публичных обновлений.
