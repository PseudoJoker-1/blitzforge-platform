# WotbMod Lua Host

Это native-пакет, который запускает установленные Lua-моды из
`<game>\mods\lua\<mod-id>` и локальные скрипты разработки из
`<game>\mods\lua-dev`.

Пакет запрашивает все 45 разрешений V3 с максимальным tier `REVIEWED`, которые
можно безопасно передать Lua без FFI. Шесть `UNSAFE`-разрешений намеренно не
запрашиваются. Каждый установленный скрипт дополнительно ограничивается своим
`manifest.json` внутри host-а.

Полное руководство поставляется в пакете как `LUA_MODS_RU.md`.
Текст лицензии встроенного Lua поставляется как `THIRD_PARTY_NOTICES.txt`.
Обычная package-сборка является локальным unsigned artifact; публичный bundle
создаётся `tools\build_public_preview.ps1` и содержит detached ECDSA P-256
подпись и доверенный публичный ключ.
