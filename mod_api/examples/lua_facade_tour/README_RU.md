# Lua Facade Tour

Пример на фасадном слое Lua API: ни одна raw-таблица (`wotb.gameplay_hud`,
`wotb.entity_public`, `wotb.events`) не вызывается по имени — только
`wotb.mod`, `wotb.players`, `wotb.battle`, `wotb.hud`, `wotb.ges`
(см. [LUA_MODS_RU.md](../../docs/LUA_MODS_RU.md), раздел «Фасады»).

Скопируйте папку как `<game>\mods\lua\example.lua_facade_tour`. Имя папки
обязано совпадать с `id` в `manifest.json`.

Что пишет в лог загрузчика (категория `facade_tour`):

- при включении — id скрипта и его права, режим HUD (`native` или
  `unavailable` с причиной клиента), список capability runtime-а со статусами
  и честный ответ `capability is not registered` на идентификатор интерфейса
  `wotbmod.gameplay.hud` (это интерфейс, а не capability), находится ли игрок
  в бою;
- через 45 с после старта боя (событие `battle.started` приходит ещё на
  экране загрузки, когда нет ни машин, ни контролов HUD) и в конце боя —
  каждую видимую машину: ник, тег клана, локализованное имя танка, фраги,
  позу (`n/a`, пока источник позы не подтверждён) и причины недоступных
  полей; в тот же момент пример красит прицел и пробует слот миникарты;
- каждый выстрел, каждое уничтожение (`X destroyed Y`), итог боя;
- первую смену режима камеры, декодированную по GES-схеме;
- режим и FOV камеры (`wotb.view.get`) через 45 с после старта; по F7
  (`wotb.keys`) — штатный toast через `wotb.screen.notify`; счётчик выстрелов
  последнего боя хранится через `wotb.store` и печатается при следующем
  включении.

Цена на кадр — ноль: `on_frame` не определён, всё приходит по событиям.
`on_disable` возвращает подписки (`battle.off_all()`, `ges.off()`,
`timer.cancel_all()`) и сбрасывает HUD (`hud.reset()`), если пример его трогал.

Ожидаемый честный отказ на клиенте 11.20.0.887: строка `minimap last-known:
hud.minimap.set_show_last_known: ... not supported` — этот слот клиент не
поддерживает, и фасад этого не скрывает.
